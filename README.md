# Milo bot · Warframe 助手

面向 **MaiBot（麦麦）** 的《星际战甲》（Warframe）国际服 PC 原生插件（版本 **1.0.0**，已验证支持 MaiBot **1.4.5** / SDK **2.21.0+** / Python **3.12**），为麦麦提供聊天 `/` 斜杠指令与 `@Tool` 自主调用能力：

- **世界状态与周期**：时效总览、平原、双衍王境、警报、裂隙、突击、执刑官猎杀、入侵、奸商、瓦奇娅、科研、新闻、钢铁之路、电波、每日特惠、1999 日历与三大赏金。
- **仲裁、遗物与效率工具**：仲裁实时与 30 天前瞻表、遗物掉落、开核桃期望、中英双向翻译、心智融合计算、Mod/赋能升级消耗计算。
- **市场与拍卖**：`warframe.market` 实时查价（含 48h/90d 统计）、金/银/铜垃圾排行、紫卡与赤毒/信条拍卖筛选、游戏内 `/w` 私聊语句生成。（**暂未添加紫卡分析功能**。）
- **主动推送与提醒**：按会话隔离的定时事件订阅（支持 UTC+8 推送时段与单次退订）和个人铸造到期提醒。

## 常用指令

| 指令 | 说明 |
| --- | --- |
| `/帮助` / `/状态` / `/时效` | 指令菜单、插件状态与实时总览 |
| `/平原` / `/轮换` / `/警报` / `/裂缝 [词]` | 周期、双衍王境、警报与裂隙（支持 `/钢铁裂缝`、`/九重天裂缝`） |
| `/突击` / `/猎杀` / `/入侵` / `/奸商` / `/瓦奇娅` | 每日/每周轮换与虚空商人 |
| `/科研` / `/新闻` / `/钢铁` / `/电波` / `/每日特惠` / `/1999` | 科研、公告与赛季活动 |
| `/地球赏金` / `/金星赏金` / `/火卫二赏金` | 三大平原赏金与奖励池 |
| `/仲裁` / `/仲裁表 [所有]` / `/遗物 <词>` / `/开核桃` | 仲裁前瞻、遗物查询与开核桃收益 |
| `/翻译 <词>` / `/融合 <当前%> [目标%]` / `/升级消耗` | 中英翻译、心智融合与升级消耗 |
| `/订阅 <类型> [条件] [时段 H1-H2] [单次]` / `/退订` / `/订阅列表` | 事件订阅管理 |
| `/铸造提醒 <物品> [时长]` / `/铸造列表` / `/取消铸造` | 本地铸造提醒（默认 `12h`） |
| `/wm 物品 [买家\|卖家] [满级] [-en]` / `/金垃圾` / `/银垃圾` / `/铜垃圾` | 市场查价与杜卡德排行 |
| `/wr <武器>` / `/cd <武器>` / `/xt <武器>` / `/w <序号>` | 紫卡/赤毒/信条拍卖检索与私聊语句生成 |
| `/紫卡分析` | 暂未添加紫卡分析功能 |

- **通用后缀**：`-1` / `-w` 输出纯文本，`-2` / `-3` 翻页，`/wm` 支持 `-en`；`/wm`、`/wr`、`/cd`、`/xt`、`/w` 支持无 `/` 前缀及 `@Milo` 艾特触发。
- **自然语言工具**：已开放 `warframe_world_query` 与 `warframe_market_query` 给麦麦自主调用。

## 安装与配置

1. 将插件目录放入 MaiBot 宿主的 `plugins/` 下（确保 `_manifest.json` 与 `plugin.py` 位于插件根目录）。
2. `_manifest.json` 已声明 `httpx>=0.28.1` 与 `pillow>=13.0.0`，Host 会在加载前自动处理依赖；插件自带 `MiSans` 字体与「相变临界」卡片纹理，无需系统字体库。
3. 首次加载后会自动生成 `config.toml` 并支持在 MaiBot WebUI 配置页修改：

| 字段 | 默认值 | 用途 |
| --- | --- | --- |
| `enabled` | `true` | 启用查询与工具 |
| `output_mode` | `image` | `image` 图片或 `text` 文字 |
| `font_path` | 空 | 指定字体路径（留空使用内置 MiSans） |
| `timeout_seconds` | `10.0` | 请求超时秒数（3～20） |
| `proxy_url` | 空 | 可选 HTTP/HTTPS 代理（如 `http://127.0.0.1:7890`；留空走系统代理） |
| `subscription_enabled` | `true` | 启用后台订阅轮询推送 |
| `subscription_interval_seconds` | `120` | 轮询间隔秒数（60～3600） |

插件数据库保存在 `ctx.paths.data_dir/milobot.sqlite3`，不改动宿主主库。
