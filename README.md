# Milo bot · Warframe 助手

当前版本：**1.0.0（正式版）**。联调目标为插件 SDK **2.21.0**、Python **3.12**。
面向 Milo bot 的原生 Python 实现；单插件部署，不需要启动其他机器人后端。

| `/紫卡分析 <武器> <词条数值...>`（或 `/wfen`） | 纯本地数学计算紫卡武器倾向、理论区间、中位偏差及区间进度条，无需 OCR |
| 通用指令后缀 `-1` / `-w` / `-en` / `-<页码>` | 任意查询附加 `-1` 或 `-w` 强制纯文本回复；支持 `-2`、`-3` 翻页；`/wm` 支持 `-en` |
| 自然语言 `@Tool` | `warframe_world_query` 与 `warframe_market_query` 已同步开放上述所有查询、计算工具与铸造提醒能力 |

所有指令均去除冗余前缀，直接 `/` 加指令即可（如 `/平原`、`/突击`、`/紫卡分析 ...`）；`/wm`、`/wr`、`/cd`、`/xt` 与 `w <数字>` 大小写不敏感且也兼容无 `/` 前缀，并支持群聊 `@Milo` 等艾特前缀。
物品、武器与遗物名称支持完整中文名、英文多词名称、市场 slug、内置词典中的别名及中文 `p` 简写。

当前只支持**国际服 PC**（含开启跨平台联机的拍卖挂单）。不包含 OCR 图片识别（紫卡倾向分析采用纯文本本地数学计算）、拼音匹配或原管理后台，且不执行任何游戏内自动交易。

## 安装

1. 解压，把完整的 `milobot_warframe` 文件夹放进宿主 `plugins` 目录。`_manifest.json` 和 `plugin.py` 必须直接位于这个文件夹下，避免多套一层目录。
2. 确认宿主 Python 环境已包含 SDK 2.21.0、httpx 0.28.1、Pillow 13.0.0。
3. 重载或重启插件后，确认日志出现 `Milo bot Warframe 插件 1.0.0 已加载`。
4. 在实际聊天中可依次输入 `/帮助`、`/状态`、`/时效`、`/裂缝 捕获`、`/科研`、`/翻译 Volt`、`/融合 38.5 60`、`/开核桃`、`/铜垃圾`、`/铸造提醒 Forma 23h`、`/wm 电男`、`/wr 托里德 爆率,爆伤 无`、`/w 1`、`/紫卡分析 托里德 +180% 暴击几率 +140% 暴击伤害` 及自然语言提问验收。

典型插件安装目录示例（按你的宿主实际安装路径为准）：

```text
<宿主根目录>\plugins\milobot_warframe
```

不同环境使用各自的插件与数据目录；发布包不附带用户配置、数据库、API 密钥或缓存。

缺少依赖时应使用对应环境的依赖管理流程；不要在宿主环境直接执行 `uv sync`，也不要把开发用的完整锁文件强制覆盖到其他插件共用的 Python 环境。

## 配置

Runner 会根据代码模型生成 `config.toml` 与 WebUI 配置表单，无需手写初始配置。

| 字段 | 默认值 | 用途 |
| --- | --- | --- |
| `enabled` | `true` | 启用查询与工具 |
| `output_mode` | `image` | `image` 图片或 `text` 文字 |
| `font_path` | 空 | 使用随包附带的 MiSans，或指定中文字体文件 |
| `timeout_seconds` | `10.0` | 单次数据源超时，范围 3～20 秒 |
| `subscription_enabled` | `true` | 启用后台订阅轮询推送 |
| `subscription_interval_seconds` | `120` | 订阅轮询间隔秒数，范围 60～3600 秒 |

保留自动生成的 `[plugin] config_version = "0.1.0"`。
默认字体随包提供，Windows、Linux 均无需依赖系统中文字库。可用 `font_path` 覆盖。
中文字体缺失或卡片生成失败时，命令退回文字回复，详细原因写入插件日志。

插件数据库为 `ctx.paths.data_dir/milobot.sqlite3`。只存公共数据响应、精简词典、订阅规则（`subscriptions`）、铸造提醒（`foundry_reminders`）与按会话独立的推送去重记录（`subscription_deliveries`），不操作宿主主库。
所有数据均按需获取，不在加载插件时下载全量导出文件或 OCR 模型：
- 世界状态缓存 30 秒，订单/杜卡德/拍卖查询缓存 60～120 秒，仲裁排期缓存 12 小时，市场物品索引缓存 24 小时；
- 别名与静态翻译词典（节点、电波、武器、紫卡武器/词条/倾向基准、玄骸武器、奖励池、仲裁分级、遗物）缓存 7 天。
- 候选选择与 `/w` 私聊语句均仅驻留实例内存并在 60/120 秒后自动过期，按会话或发送者严格隔离。
网络失败、限流和数据格式变化会明确返回查询失败，不会显示成“暂无数据”。

## 开发与验证

在本项目的独立目录中使用 `.venv` 或 `uv`：

```powershell
.\.venv\Scripts\ruff.exe check .
.\.venv\Scripts\ruff.exe format --check .
.\.venv\Scripts\ty.exe check
.\.venv\Scripts\python.exe -m pytest -q
.\.venv\Scripts\python.exe -m pip_audit --disable-pip --require-hashes -r requirements.lock.txt
.\.venv\Scripts\python.exe scripts/live_smoke.py
.\.venv\Scripts\python.exe scripts/design_preview.py
```

`uv.lock` 固定开发环境，`requirements.lock.txt` 含运行依赖的哈希。
`requirements.txt` 是插件直接依赖清单；它们的用途不同。

## 卡片设计

所有图片卡片统一使用「相变临界」白底、淡几何纹理、蓝色标题、紫色重点数值与浅色状态标签。
长名称、标题与说明自动换行；宽度统一为 1080 像素，高度随内容变化。

卡片视觉素材来源于 B 站视频作者（详见 [ASSET-SOURCES.md](ASSET-SOURCES.md)），内置字体为 MiSans。
